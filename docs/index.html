    Help

    Installing

    How do I install the APK?

    Download it on your phone and open it. If Android asks, allow your browser to install apps, then tap Install.

    Play Protect warns about the app

    Stickshot isn't on the Play Store, so Play Protect doesn't know it yet. Tap More details, then Install anyway.

    How do I install on Windows?

    Download the installer and run it. It doesn't need admin rights and adds Start Menu and Desktop shortcuts. If Windows SmartScreen shows a warning, click More info, then Run anyway. Uninstall any time from Apps & Features.

    Can Android, Windows and browser players play together?

    Yes. Online games mix all three platforms, up to 16 players. Everyone just needs the same version.

    How do I update?

    The Android app shows an UPDATE button on the main menu when a new version is out. On Windows, download and run the latest installer. The browser version updates itself.

    My friend can't see my online game

    Both of you need the same version. Update, then look in Available games, or tap Refresh.

    Can I play over Wi-Fi / LAN?

    Yes, on Android and Windows: devices on the same Wi-Fi find each other automatically with no internet needed. Browsers can't do local LAN, so the browser version plays online.

    How responsive are the multiplayer controls?

    Stickshot features ultra-snappy controls tuned to feel like zero delay in multiplayer, on Android, Windows or in your browser.

    Voice chat doesn't hear me

    Allow the microphone when the game asks. Settings › Voice & chat › Mic test shows a bar that moves when you speak.
